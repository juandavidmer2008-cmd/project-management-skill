# Dashboard ejecutivo visual

## Cómo abrirlo
Abre `dashboard/index.html` en un navegador. No requiere instalación ni conexión a internet.

## Diseño
- Paleta ejecutiva azul: navy `#0B1F3A`, azul corporativo `#1769E0`, azul claro `#3E8BFF`.
- Fondo neutro para mejorar la legibilidad.
- Tarjetas con jerarquía visual y sombras discretas.
- Diseño responsive para escritorio, tablet y móvil.
- Vista preparada para impresión mediante el botón **Export report**.

## Componentes
- Cuatro KPI principales.
- Gráfico de progreso planificado vs. real.
- Indicador circular de salud del portafolio.
- Tabla de iniciativas prioritarias.
- Acciones para liderazgo.
- Watchlist de riesgos.

## Personalización
Edita los valores directamente en `index.html` y los colores globales en `styles.css`. Los CSV de `../templates/` pueden utilizarse como fuente de datos para conectar el dashboard con Excel o Google Sheets.
